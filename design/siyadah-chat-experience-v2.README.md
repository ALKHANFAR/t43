# معاينة الموظف ومساحته الواحدة

الموظف هو مدخل العمل. الرئيسية تعرض نظرة خفيفة على الأدوار القريبة وآخر تكليف محلي محفوظ. فتح الموظف يعيد مسودته وتوجيهه وسجل تكليفاته، وتظهر النتائج وطريقة العمل كتفاصيل داخل نفس المساحة. لا صفحات مستقلة للتكليفات أو النتائج، ولا أدوات في مربع الكتابة.

الموظفون أدوار توضيحية وليسوا حسابات مُنشأة أو منفذين. الحفظ في ذاكرة الصفحة ويزول عند إعادة التحميل. لا API أو نموذج أو مؤقتات تنفيذ أو مخرجات مزود؛ النتائج فارغة وتقول ذلك. الحفظ لا يعني إرسالًا أو تنفيذًا، والمساحة ليست واجهة الإنتاج.

## العدد والوصول

البيانات التجريبية تحتوي20وظيفة مألوفة لاختبار كثرة الموظفين فقط. لا حد منتج بهذا العدد ولا تصنيف للطلب بحسب العدد. البحث يشمل كامل المجموعة بالوظيفة أو وصف الشغل. ترتيب القريبين يعتمد على آخر استخدام محلي؛ `recentVisible` إعداد عرض قابل للتغيير، ولا يخفي البيانات من البحث. نفس الرحلة تعمل مع مجموعة فارغة أو موظف واحد أو مجموعة أكبر، دون شبكة20بطاقة.

التوجيهات والمسودات والتعديل وسجل التكليفات وحالة فتح التفاصيل محفوظة لكل موظف على حدة. أسماء الأدوات المرتبطة بالمثال داخل تفاصيل طريقة العمل فقط؛ لا حسابات متصلة أو صلاحيات تشغيل. الشعارات تستخدم روابط الكتالوج عبر CDN؛ فشل تحميلها لا يؤثر بالحفظ.

## التحقق

`node --test scripts/chat-experience-preview-runtime.test.mjs`: ثلاث حالات مهمة — بحث20دورًا بالوظيفة أو العمل، عزل التكليف/المسودة/التوجيه والعودة من الرئيسية، ومجموعتا0و37دورًا بلا حد سعة. الاختبارات ترفض timers/API وتتحقق من عدم اختلاق نتائج. HTML/JS/feature index مفحوصة. Chrome1440×960 و390×844: بحث الموردين→المشتريات→حفظ تكليف ومسودة جديدة→الفواتير فارغة→عودة تستعيد مسودة المشتريات وتكليفها؛ composer ظاهر وبلا تجاوز أفقي. الصور في/tmp دليل واجهة توضيحية فقط.

افتح `siyadah-chat-experience-v2.html` عبر خادم الملفات المحلي. خط الجهاز Tahoma/Arial، زر بنفسجي وشعار سيادة الموجود؛ مراجع21st السابقة سياق بحث وليست مكونات React مثبتة أو تصميمًا نهائيًا معتمدًا. لا تعديل app/server أو نشر.
