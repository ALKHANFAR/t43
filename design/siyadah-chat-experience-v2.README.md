# معاينة تجربة سيادة — الإصدار الثاني

معاينة مستقلة محلية، وليست واجهة الإنتاج أو تشغيل مزود. افتح `siyadah-chat-experience-v2.html` عبر خادم ملفات محلي. البيانات والتوقيتات توضيحية؛ لا توجد اتصالات API أو نموذج أو حسابات. السياق المختار لا يعني اتصالًا أو صلاحية.

## التفاعل

الأمثلة تملأ الطلب؛ الإرسال يبدأ العرض. يمكن البحث عن الأدوات وإضافة سياق وإزالته، فتح تفاصيل الخطوات، إلغاء العرض وإعادته مع حفظ التوجيه التالي، مراجعة النتيجة، تنزيل مسودة محلية، والعودة عبر السجل. مسار المثال يستخدم Sheets وAsana دائمًا؛ الأدوات الأخرى سياق مختار فقط. الاتجاه يتبدل دون ادعاء ترجمة اللغة.

## المصدر والتصميم

التكوين يستند إلى صورة المفهوم الناتجة في جلسة 8 أكتوبر وإلى اتجاه المؤسس المسجل في `docs/experience/experience-direction-20261008.md`: خط الجهاز، زر بنفسجي، شعارات الأدوات الأصلية، ونصوص عربية موجزة. استُخدم Tahoma قبل Arial بعد فحص Chrome لأن fallback العربي لـArial ظهر بشكل غير مناسب.

مرجع البنية: https://ui.heygaia.io/r/tool-calls-section.json — أيقونات متراكبة، طي المسار، عمود اتصال الخطوات، وتفاصيل كل خطوة. التنفيذ هنا مكتوب مستقلًا لـDOM ثابت؛ **لم يُثبت مكون React الأصلي**. لم يُنسخ مصدر TSX، ولم يعلن سجل المرجع حقل ترخيص. شعارات الأدوات من روابط الكتالوج الموجود `data/tool-icon-sources.json`؛ تعتمد على وصول CDN.

## مقارنة التكوين بخمس نقاط

1. العمود الأيمن الهادئ، زر الطلب البنفسجي، والتنقل محفوظة؛ الحساب عام بلا هوية وهمية.
2. الرسائل ومسار العمل والنتيجة متصلة بالمحاذاة اليمنى؛ لا تظهر نتيجة قبل انتهاء المثال.
3. طبقات تفاصيل المسار والنتيجة قابلة للفتح، وليست بطاقات ثابتة فقط.
4. مربع الكتابة وشرائح الأدوات أسفل الشاشة؛ اختيار الأدوات فوقه محدود الارتفاع.
5. حذف الزخارف والشعار المتخيل والنص الترويجي؛ يظهر تنبيه المعاينة دائمًا، مع RTL والهاتف وتقليل الحركة.

## التحقق

اختبارات السلوك: `node --test scripts/chat-experience-preview-runtime.test.mjs` (أربع حالات: الاختيار، الإلغاء، النتيجة والتنقل، وحفظ مسودة التوجيه مع أدواتها). فحص HTML وJS وfeature index. فحص Chrome عند1440×960 و390×844؛ لا overflow أفقي، composer ظاهر. اللقطات خارج المستودع في `/tmp`؛ هي دليل واجهة توضيحية فقط.

## تبسيط الواجهة — الجولة الثانية

المسار مطوي افتراضيًا ويعرض الفعل الحالي وشعاراته فقط. بعد اكتمال المثال تظهر النتيجة أولًا: ملخص وطلب واحد، والجدول وراء «اعرض الطلبات». عبارة «طلب ناقص» في المثال تفتح سؤال أولوية واحدًا دون اختيار مسبق؛ الجواب يغيّر ترتيب الطلبات، ويُحفظ كسطر قابل للتعديل. الأجوبة الحرة محفوظة، وترتيبها المحلي يبدأ بطلب استكمال المعلومات. اقتراح Sheets وAsana يظهر فقط أثناء كتابة مثال العملاء/الطلبات/المتابعة؛ اختيارها يضيف سياقًا قابلًا للإزالة ولا ينفذ عملًا. هذا تطابق كلمات محلي للمعاينة، وليس ذكاء نموذج.

مرجع التفاعل الذي بحثه مسار التنسيق: [Compose](https://21st.dev/@laziekiki/components/compose)، [InputBar](https://agent-elements.21st.dev/docs/input-bar)، [QuestionTool](https://agent-elements.21st.dev/docs/question-tool). استُلهم اختيار السياق والسؤال القصير والانهيار إلى جواب قابل للتعديل؛ لم تُثبت مكونات React الأصلية.

أصبحت اختبارات السلوك ست حالات، بما فيها اختلاف ترتيب الجواب وحفظ النص والتركيز والتحديد أثناء انتقال الخطوة. فحص Chrome محدود بثلاث رحلات: السؤال والنتيجة، كشف الجدول وتفاصيل الطلب، والمقترحات والإلغاء والعودة للسجل. المقاس390 بلا تجاوز أفقي؛ اللقطات توضيحية فقط.
