# Siyadah AI

هذا مستودع واجهة سيادة وخادمها الحالي. يحتوي على صفحات الواجهة و`server.mjs` وخدمات هوية الشركة وبياناتها وربط Activepieces. مستودع `77766` غير معتمد لهذا العمل بقرار المستخدم؛ لا يؤخذ منه كود ولا يُبنى عليه ربط أو نشر. أي اعتماد موجود عليه يحتاج كشفًا ومعالجة في `t43` قبل اعتباره مستقلًا. راجع `AGENTS.md` لطريقة العمل المتوازي و`ARCHITECTURE.md` لخريطة الأجزاء بعد دمجها. حالة الإنتاج والفرع المنشور تحتاج تحققًا مباشرًا قبل أي تغيير.

| المسار | المحتوى |
|---|---|
| `/` | الموقع: `index.html` (EN) · `ar.html` (AR) · `integrations.html` · `demo.html` · `privacy.html` |

## النشر

الواجهة والخادم الموجودان في هذا المستودع ليسا موقعًا ثابتًا فقط. عند مراجعة 1 أكتوبر 2026، كانت خدمة `siyadah-direct-ui` على Railway تنشر الفرع `codex/siyadah-integration-20260930` عند الالتزام `692cc690`؛ تحقق من Railway والفرع الفعلي قبل أي دمج أو نشر. رفع الملفات إلى GitHub Pages أو `public_html` لا يشغّل `server.mjs` ولا مسارات الحساب وقاعدة البيانات.

## التسجيلات
نموذج التسجيل التسويقي القديم مهيأ للإرسال إلى ويب هوك Activepieces. يلزم تحقق حي من حفظ التسجيل ووصول إشعار البريد قبل اعتبارهما منجزين.
الرابط والإعدادات لنموذج التسجيل القديم في بلوك `CONFIG` أول `site.js` (ملف واحد للصفحتين، النصوص تُختار حسب `<html lang>`). هذا الوصف يخص النموذج التسويقي، ولا يصف حسابات التطبيق أو API سيادة.

## شات التطبيق الحقيقي

`app/chat.js` لا يتصل بـ Activepieces مباشرة. يستخدم افتراضيًا المسار
`/siyadah-api/v1/chat` على خادم `t43` نفسه، ويمكن ضبط `window.SIYADAH_CHAT_GATEWAY`
عند الحاجة. الخادم يتحقق من جلسة العميل ونطاق شركته قبل أي تكامل.
ملف `nginx.conf` القديم لا يصف نشر Docker الحالي، وفيه proxy قديم إلى خدمة خارجية؛
لا تستخدمه للنشر قبل إزالة هذا المسار ومراجعته.

الرد يستطيع حمل `SiyadahFlowAcceptanceV1` أو `SiyadahFlowAcceptanceV2`، وتعرض الواجهة ما تم إثباته وما
بقي من عشر بوابات مستقلة. تعرض الواجهة «المسودة جاهزة 10/10» عندما تكتمل
المسودة المعطلة وتصبح جاهزة لربط الحسابات. ويظل إثبات التشغيل والأثر منفصلاً؛
لا يظهر وصف «نتيجة تشغيل مثبتة 10/10» إلا عندما يعيد الخادم
`can_claim_10_of_10: true` بعد إثبات التشغيل ونتيجة المزود والأثر التجاري.
